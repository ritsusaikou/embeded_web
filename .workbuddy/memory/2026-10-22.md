## 轻量化个人博客（personal light web 项目）

- 用户需求：可部署在 **512MB 内存 Linux 机器**上的轻量个人博客；确认方案为 Markdown 文件管理 + 基础博客/标签归档（无搜索/评论）。
- 技术选型：**Astro 5 纯静态输出**（零 JS 页面）+ 服务器仅跑 Nginx（常驻约 15MB）。本地构建，rsync 上传 dist/。
- 已完成：项目骨架（package.json / astro.config.mjs / content.config.ts）、全套页面（首页/文章页/标签云/标签页/按年归档/关于/RSS/sitemap/favicon）、浅色主题样式（src/styles/global.css）、4 篇示例文章、deploy 目录（nginx.conf 小内存优化 + server-init.sh + deploy.sh 一键部署）、README。
- 已完成：全部开发与验证。npm install 需用 `--registry=https://registry.npmmirror.com`（默认源极慢且会挂起）。
- 构建结果：14 页面 / 19 文件 / 共 90KB，页面零 JS；`rss.xml.js` 含 TS 类型语法须为 `.ts` 后缀（踩坑记录）。
- 本地预览：`npm run preview` → http://127.0.0.1:4321/（trailingSlash:'never'，访问不带尾斜杠）。
