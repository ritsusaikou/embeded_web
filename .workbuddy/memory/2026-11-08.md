## 补充：板上无 apt 的备选路径

在 `deploy/MANUAL-board-nexuslink.md` 增加「附一」，四条方案按省事排序：A 用 Buildroot/Yocto 把 nginx 编进镜像；B 用 frpc 的 `static_file` 插件直接发静态文件（零额外依赖，板上不要 Nginx）；C busybox httpd；D 交叉编译 nginx（`--without-http_rewrite_module` / `--without-http_gzip_module` 绕开 PCRE 与 zlib，代价是要删掉配置里的正则 location 和 gzip_static）。
关键结论：服务器侧（DNS/证书/frps/443 反代）与板上用什么 Web 服务器无关，换方案不影响第 6–10 步。

## 方案 A 已展开为 A-0 ~ A-7

Buildroot 主线：认 `.config`（别 defconfig 覆盖）→ menuconfig 勾 nginx（gzip_static + pcre，不勾 ssl）→ `make nginx` 只编包 → **从 `output/target/` 直接取二进制走 tar|ssh，不必重烧** → 板上补 `/var/log/nginx`、`include conf.d/*.conf`（Buildroot 默认没有）→ 需要时用 `BR2_ROOTFS_OVERLAY` 固化进镜像 + `make savedefconfig`。
Yocto 差异：加 `meta-webserver` 层、`PACKAGECONFIG:append:pn-nginx = " http-gzip-static"`、`bitbake -e nginx` 查真实开关名。
